## Installation

### Option 1: Visual Studio Code Marketplace

1. Open the Extensions view in VS Code.
2. Search for **Dark 2026 Contrast**.
3. Select **Install**.
4. Open the Color Theme picker and choose **Dark 2026 Contrast** or **Dark
   2026 High Contrast**.

### Option 2: Manual VSIX installation

1. Download the `.vsix` file from the latest GitHub Release.
2. In VS Code, open the Command Palette.
3. Run **Extensions: Install from VSIX...**.
4. Select the downloaded file.

Alternatively, install it from a terminal:

```powershell
code --install-extension .\<name>.vsix
```
